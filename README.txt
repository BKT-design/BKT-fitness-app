BKT FITNESS APP — PWA starter
Made by BKT Developer

IMPORTANT
- This is a Progressive Web App (PWA), not an APK.
- To install it from Chrome as an app, the files must be hosted on an HTTPS website.
- After the first successful visit, the app shell works offline. Saved entries stay in this browser on this device.
- Do not clear Chrome site data if you want to keep the local history.
- This starter does not sync data between devices.

HOW TO PUBLISH (one-time setup; easiest with a computer)
1. Create/sign in to a GitHub account.
2. Create a new public repository named bkt-fitness-app.
3. Upload all files in this folder (index.html, style.css, app.js, manifest.webmanifest, sw.js, icon.svg).
4. In repository Settings > Pages, choose Deploy from a branch, select main and /(root), then Save.
5. Wait for the GitHub Pages website link to appear.
6. Open that HTTPS link in Chrome on Android. Use Chrome menu > Install app or Add to Home screen.

Once the page has loaded successfully, the app can work offline on that phone.
For best results, use the latest Chrome. This PWA is a starter version and not a medical tool.
